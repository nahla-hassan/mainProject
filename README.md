# ClassCrest - Student Management System

## Overview
**ClassCrest** is a web-based **Student Management System** built with **Django**.  
It helps schools and colleges **manage student records, attendance, marks, and timetable** efficiently in one place.

---

## Features
- ✅ Add, edit, and delete student information  
- ✅ Record and track student attendance  
- ✅ Manage student marks and grades  
- ✅ View class timetables  
- ✅ Teacher and student dashboards  
- ✅ Responsive design for desktop and mobile

---

## Technology Stack
- **Backend:** Django (Python)  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** SQLite (can be switched to MySQL/PostgreSQL)  
- **Version Control:** Git & GitHub
